# 사용 안내

macOS 26 이상에서 `dist/꼬꼬무.app`을 실행합니다. 생성은 기존 Codex CLI의 ChatGPT 로그인을 사용합니다. 설정(⌘,)의 **연결 확인**에서 준비 상태를 확인하세요. 첫 화면의 **샘플 둘러보기**로 질문과 입력 화면을 살펴볼 수도 있습니다.

1. **새 학습**에서 주제를 적고, 필요하면 소주제와 프로젝트 경험을 붙여넣습니다.
2. 질문 하나에 직접 답하거나 외부에서 전사한 텍스트를 붙여넣고 **답변 제출**을 누릅니다.
3. 피드백을 읽고 **참고 답안과 해설**을 펼치거나 **다음 꼬리 질문**으로 이어갑니다. 같은 질문에 다시 답해도 이전 답변은 남습니다.
4. 기본 네 질문을 마치거나 **여기까지 마무리**를 눌러 복습할 질문을 고릅니다.
5. **오늘 복습**에서 예전 답을 보기 전에 다시 답하고, 스스로 평가해 다음 일정을 정합니다.

질문은 짧은 제목, 상황과 조건, 핵심 질문으로 나누어 표시합니다. 본문은 기본 17pt이며 상단 읽기 설정에서 크기를 바꿀 수 있습니다. 기존 기록은 원문을 유지합니다.

모르면 힌트나 **모르겠어요**로 시작하세요. 근거가 의심되면 **근거 재검토**로 공식 자료를 확인할 수 있습니다. 질문 생성과 피드백에는 인터넷 연결과 Codex 사용 가능 한도가 필요합니다.

| 단축키 | 동작 |
|---|---|
| ⌘N | 새 학습 |
| ⌘Return | 답변 제출 |
| Return | 답변 입력 중 줄바꿈 |
| ⌘. | 생성 취소 |
| ⇧⌘R | 오늘 복습 |
| ⌘, | 설정 |
| ⌘+ / ⌘- | 글자 크게 / 작게 |
| ⌘0 | 기본 17pt |

## 기록과 백업

초안, 질문, 답변 시도, 피드백과 복습 일정은 `~/Library/Application Support/Tail/library.sqlite`에 저장됩니다. 창을 닫거나 앱을 종료한 뒤에도 이어서 사용할 수 있습니다. 생성 취소나 실패 후에는 저장된 답변으로 재시도합니다.

개발 중 이름인 Tail에서 꼬꼬무로 이름을 바꿔도 기존 저장 위치와 설정을 유지합니다. 학습 기록을 옮기거나 다시 등록할 필요가 없습니다. 개인 학습 데이터와 백업은 이 소스 저장소에 포함되지 않습니다.

**학습 → 보관함 백업**으로 SQLite 백업을 저장하고 **백업 복원**으로 가져옵니다. 복원 전 기존 보관함은 같은 저장 폴더의 `recovery-*.sqlite`에 보관됩니다. 백업에는 경험과 답변 원문도 포함됩니다. 앱이 보관함을 읽지 못하면 원본을 초기화하지 않고 저장 폴더를 안내합니다.

기록은 로컬에 저장되며 생성에 필요한 주제, 경험, 답변 맥락은 Codex로 전달됩니다. 앱 내 녹음, 전사는 제공하지 않습니다. AI의 피드백은 학습을 돕는 참고 자료이며, 조회 여부와 출처를 함께 확인할 수 있습니다.
