# QA 기록

## 2026년 10월 12일 저장과 복습 기반

macOS 27.0.1 arm64, Swift 6.4, SDK 27.0. Swift 6 언어 모드로 빌드했다.

Swift Testing 7개 통과: 중복 제출 방지와 기존 답변 보존, 중단된 답변 복구, 다른 세션의 부모 질문 거부, 1/3/7일과 자기평가 일정, SQLite 재실행과 백업 복원 및 오래된 저장 무시, 손상된 백업 거부, 세션 삭제 후 관계 정리.

이 단계의 검증은 저장과 학습 규칙을 대상으로 한다. 실제 화면과 실제 생성 결과는 아래 단계에서 별도로 기록한다.

## Codex 연결과 생성

기존 ChatGPT 로그인, Codex CLI 0.162.1로 격리된 `work/qa-live`에서 실제 첫 질문과 제출 답변 평가를 각각 한 번 생성했다. MAX(id)+1의 동시성 문제를 주제로 답변의 유일성 제약 설명에 이어 재시도 범위와 한계를 묻는 질문이 생성됐다. 개인 이력서나 실제 경험은 사용하지 않았다.

프로세스 입력 15,000줄 왕복, 자식 프로세스를 포함한 취소, 타임아웃, 완료/실패 이벤트 동시 판별, 빈 평가 거부를 포함해 자동 테스트 12개를 통과했다. 실제 생성은 구조 검증과 질문/답안의 내용 검토를 수행했으며 모든 CS 사실의 정확성을 보증하는 검사는 아니다.

## 학습 화면과 통합 검증

최종 `./scripts/check.sh`에서 포맷 검사, 자동 테스트 15개, Release 빌드를 통과했다. 추가된 화면 상태 테스트는 제출 답변의 저장과 꼬리 질문 중복 방지, 복습 시 답안 숨김과 자기평가 중복 방지, 실패한 답변의 원문 보존과 같은 시도로 재시도를 확인한다. 고정 CLI 응답을 사용한 자동 테스트이며 실제 AI 품질 검사와 구분한다.

패키징한 Tail.app을 실제 실행하고 컴퓨터 사용 도구로 다음 흐름을 확인했다. 테스트 데이터와 읽기 설정은 `--data-dir work/qa-live`로 격리했다. 처음에는 도구의 앱 접근 승인이 차단됐으나 사용자 승인 후 정상 접근해 화면 검증을 진행했다.

| 검증 | 실제 확인 결과 |
|---|---|
| 새 학습 | 주제, 소주제, 태그만 입력해 첫 질문을 생성했다. 경험이 없음을 명시한 가정 질문이 나왔다. |
| 텍스트 입력 | 한글 여러 줄과 SQL 붙여넣기, Enter 줄바꿈, Command-Return 제출을 확인했다. 33,600자 붙여넣기에서는 길이 안내와 제출 비활성화를 확인했다. |
| 재실행 | 작성 중 앱을 종료하고 다시 실행해 질문 위치, 한글 초안, 줄바꿈과 코드 원문을 복구했다. |
| 취소와 재시도 | 실제 생성 중 취소 후 원문이 남고 재시도로 같은 시도의 평가가 완료됐다. |
| 피드백과 답안 | 피드백은 즉시 표시되고 참고 답안은 접힌 상태로 시작했다. 펼친 답안과 고정폭 SQL 코드 표시를 확인했다. |
| 근거 재검토 | PostgreSQL 17의 제약 오류와 롤백 범위를 공식 문서로 재검토했다. 출처 세 개와 수정된 설명, 재검토 전 피드백 사본이 남았다. |
| 복습 | 마무리한 세션에서도 재답변 전에 요약과 과거 답안을 숨겼다. 재답변 뒤 실제 이전 답변과의 비교, 자기평가, 다음날 일정과 오늘 목록 갱신을 확인했다. |
| 백업 복원 | 앱의 저장 창으로 백업한 뒤 복습 질문 하나를 제외하고 복원했다. 두 질문의 복습 일정과 답변 이력이 복구됐고 기존 보관함의 recovery 사본이 생겼다. |
| 읽기 | 기본 18pt와 최대 36pt, 밝은 테마와 어두운 테마, 1160px와 약 820px 폭에서 본문 스크롤과 하단 조작 접근을 확인했다. |
| 검색창 | 실제 실행에서 사이드바 최소 폭 205px, 짧아진 ‘학습 기록 검색’ 문구가 잘리지 않는 것을 확인했다. |
| 문구 | 화면의 가운뎃점을 제거하고 생성 프롬프트에도 같은 규칙을 반영했다. |

실제 AI 호출은 첫 질문 생성 두 번, 최초 평가, 꼬리 질문 평가, 공식 자료 재검토, 복습 평가를 합쳐 여섯 번 완료했다. 추가 한 번은 취소 흐름 확인을 위해 중단했다. 예시 경험은 학습용 가정이며 개인 이력서는 전송하지 않았다.

사용자가 선택한 빨간 머리띠 아이콘을 Icon Composer 형식으로 컴파일했다. 원본과 결과 체크섬, 앱 번들의 코드 서명, 실행 파일과 Swift 오브젝트의 최소 OS 26.0 및 SDK 27.0을 확인했다. 처음 CLT 재빌드에서 발생한 TestingMacros 탐색 오류는 전체 Xcode 도구 모음을 해당 명령 안에서 사용해 해결했다.

## 확인 범위의 한계

실행 환경은 macOS 27.0.1 Apple Silicon 한 대다. macOS 26 실기기, Intel, VoiceOver 실제 낭독과 물리 키보드의 한글 IME 조합은 별도로 검증하지 않았다. 한글 붙여넣기와 저장, 접근성 트리의 입력 이름과 주요 버튼, 키보드 단축키는 확인했다. AI 결과는 위 주제들의 내용과 근거를 검토했으며 임의의 CS 주제 전체에 대한 정확성을 보증하지 않는다. 현재 결과물은 로컬 개인 사용용 ad-hoc 서명 앱이다.
