# 구현 구조와 데이터 계약

Swift Package Manager와 Swift 6 언어 모드로 빌드한다. TailCore는 UI와 분리된 학습 모델, SQLite 저장소와 Codex 클라이언트를 제공한다. TailApp은 메인 액터의 화면 상태와 네이티브 화면을 담당한다.

SQLite의 session, question, attempt, review 테이블은 외래 키로 관계를 보존한다. 각 행의 버전 가능한 JSON payload에는 본문과 해당 시점의 생성 결과를 담는다. 저장은 actor에서 직렬화하며 수정된 행만 트랜잭션으로 반영한다. 초안은 지연 저장하고 제출, 화면 이동과 종료 때 즉시 반영한다. UI 변경마다 증가하는 revision으로 오래된 저장 요청이 최신 상태를 덮지 않게 한다.

제출한 답변은 AI 호출 전에 저장한다. 답변별 상태는 pending, complete, failed이며 실패한 동일 시도의 재시도는 새 답변을 만들지 않는다. 다시 답하기는 별도 시도를 만든다. 피드백 재검토는 기존 결과의 사본을 남긴다. 취소 후 도착한 결과는 작업 식별자와 취소 상태로 차단한다.

복습 일정은 원래 질문당 하나다. 설명 가능이면 1, 3, 7일 단계가 올라가고 이후 7일을 유지한다. 조금 헷갈림은 현재 단계를 유지하고 다시 필요는 첫 단계로 되돌린다. 일정은 사용자의 Calendar 기준 날짜 연산을 사용한다. AI는 일정을 직접 바꾸지 않는다.

백업은 일관된 SQLite 스냅샷이다. 복원 전 형식, 스키마 버전, quick_check, foreign_key_check 및 payload의 관계를 검증한다. 기존 DB의 복구 사본을 만든 뒤 트랜잭션으로 교체한다. 미래 버전이나 손상된 파일은 거부하고 원본을 유지한다.

Codex는 사용자 설정을 변경하지 않고 저장된 ChatGPT 인증을 사용한다. 생성은 ephemeral, read-only 실행으로 이루어지며 앱과 셸 도구를 끄고 공식 웹 자료만 필요에 따라 조회한다. 프롬프트는 표준입력으로 보내며 작업 폴더는 완료 및 실패 후 정리한다. 구조화된 JSON과 완료 이벤트를 함께 확인한다. 프로세스 그룹을 사용해 취소 시 자식 프로세스까지 정리한다.
